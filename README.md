# Privacy Portfolio

Welcome to my Privacy Portfolio.

This repository documents my transition from a corporate legal background into Privacy, Data Protection, Information Security and Governance through practical, project-based learning.

Rather than presenting only final reports, this portfolio captures the progression of realistic privacy engagements—from planning and stakeholder interviews to analysis, documentation, reflection and final deliverables.

## Portfolio Objectives

This portfolio aims to demonstrate my ability to:

- Understand GDPR requirements and core privacy principles.
- Apply privacy concepts to realistic business scenarios.
- Produce professional documentation used by Privacy and GRC teams.
- Develop practical skills in privacy governance, risk assessment and compliance.
- Build a body of work that reflects both technical learning and professional growth.

## Projects

This repository will include five simulated privacy projects based on fictional organisations:

1. Data Inventory & Article 30 Record of Processing Activities (RoPA)
2. GDPR Gap Assessment
3. Data Protection Impact Assessment (DPIA)
4. Personal Data Breach Assessment
5. Privacy by Design Review

Each project is developed progressively, documenting not only the final deliverables but also the learning process, analysis and decision-making behind them.

## Disclaimer

All organisations, people and scenarios presented in this repository are entirely fictional and have been created for educational and professional development purposes.

This repository does not describe work performed for any real client or employer.
